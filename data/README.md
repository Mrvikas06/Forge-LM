# Data Directory

Stores datasets at every stage of the pipeline.

## Dataset: TinyStories

Source: [Kaggle - TinyStories Narrative Classification](https://www.kaggle.com/datasets/thedevastator/tinystories-narrative-classification)

Short synthetic stories (3-4 year old vocabulary) generated by GPT-3.5/GPT-4.
Ideal for training small language models from scratch on consumer hardware.

| Split | Rows | File |
|---|---|---|
| Train | ~20.5M | `raw/train.csv` |
| Validation | ~202K | `raw/validation.csv` |

## Directory Structure

| Subdirectory | Purpose |
|---|---|
| `raw/` | Original downloaded CSV files (unmodified). |
| `processed/` | Cleaned plain-text files (one story per line). |
| `tokenized/` | Tokenized and chunked data ready for training (Phase 2). |

## Processing

Run the data processing script to clean raw CSVs into plain text:

```powershell
python scripts/prepare_data.py
```

For a quick test with limited samples:

```powershell
python scripts/prepare_data.py --max-samples 10000
```

Data files are excluded from Git via `.gitignore`.
